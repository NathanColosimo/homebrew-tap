# NathanColosimo/homebrew-tap

Homebrew tap for [Eighty](https://github.com/NathanColosimo/eighty): free battery
charge limit and heat protection for Apple silicon MacBooks.

```sh
brew install --cask nathancolosimo/tap/eighty
```

Casks here are updated by Eighty's release script. Report problems in the
[Eighty repo](https://github.com/NathanColosimo/eighty/issues).
